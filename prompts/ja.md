# Waddly用キャラクタースプライトシート生成プロンプト

Waddlyは、この共通仕様と1つの[画風ブロック](pixel-art-ja.md)、キャラクターの説明を組み合わせます。初期設定はピクセルアートです。そのままコピーできる初期プロンプトは[README](../README.ja.md#画像を用意する)にあります。

手作業で組み合わせる場合は、下の `{{character}}` を説明に置き換え、[ピクセルアート](pixel-art-ja.md)、[手描き](hand-drawn-ja.md)、[アイコン](iconic-ja.md)、[レトロアニメ](retro-cartoon-ja.md)、[アニメ](anime-ja.md)、[切り絵](paper-cutout-ja.md)のうち1つの `text` ブロックを末尾に追加してください。Markdownの囲み記号は含めません。アプリは入力した説明をそのまま挿入し、説明中のテンプレート記号を解釈しません。

説明が空欄か空白だけの場合は、次の説明を使います。

```character
青いニット帽をかぶった丸いペンギン。黒い背中、白いお腹、短いオレンジ色の足。
```

## 共通仕様

```text
作りたいキャラクター：{{character}}

このキャラクターで、Waddly用の3×3スプライトシートを1枚作成してください。参考画像を手動で添付した場合は、その個体の特徴を保ってください。参考画像は任意です。

【キャラクターと静止ポーズ】
- 種類、顔、体の幅と高さ、配色、装飾品、向き、カメラ、大きさを9コマすべてで統一する。
- 頭の上端、体の下端、左右の中心を各セルの同じ座標に固定する。ポーズごとに拡大縮小や位置移動をしない。
- 小さなデスクトップペットで見やすい少数の静止ポーズにする。滑らかな全身運動ではなく、待機とまばたき、タイピングの差は小さくし、うとうとと睡眠では体の輪郭を保つ。大きな表情変化はEnterの反応に限り、体の基準位置は動かさない。

【シートと配置】
- 正方形の透過PNGを1枚出力する。同じ大きさの正方形セル9個を3×3に並べ、画像の辺の長さは3で割り切れる値にする。
- 本物のアルファ透過を使い、キャラクターと小道具の外側はアルファ0にする。偽のチェッカー柄、色付き背景、地面、投影する影は描かない。
- キャラクター全体、装飾品、キーボード、エフェクトは各セルの中央50%に収め、四辺に25%ずつ安全な余白を取る。セル境界への接触や隣のセルへのはみ出しは禁止。
- 収まらない場合はキャラクターを縮小せず、動作やエフェクトを控えめにする。コマ間の溝、区切り線、枠、番号、説明文、ロゴ、透かしは禁止。任意のEnterキー記号以外の文字は入れない。

【9コマ：左上から右へ、上から下】
1. 待機：リラックスして座っている。
2. まばたき：1コマ目と同じ姿勢で、まぶただけを閉じる。
3. キーボードに集中：注意を向け、手を構える。
4. タイピング：小さくゆっくりキーを押す。
5. タイピングの変化：4コマ目から手の位置だけを少し変える。
6. 高速タイピング：少し前傾し、手を速く動かす。体の基準位置は固定する。
7. Enterキーの反応：大きめのEnterキーを勢いよく押し、表情を強調する。基準位置は保つ。
8. うとうと：待機時の位置に座ったまま、まぶたが重くなる。
9. 睡眠：8コマ目と同じ座った輪郭で目を閉じ、休んでいる。

【キーボードとエフェクト】
- キーボードは3〜7コマ目だけに描く。登場するすべてのコマで位置、形、大きさ、遠近感、色を統一し、幅はセルの40%以下にする。
- 7コマ目だけEnterキーを強調し、セル幅の30%以内に収める。「↵」記号は任意だが、「Enter」の文字は書かない。
- Enterのきらめきと2本以下の短い衝撃線は体のそばの安全範囲に収め、隣のセルには描かない。

以上の条件と、続く画風の指定に合うスプライトシート画像だけを出力してください。
```

## 確認と修正

ChatGPTなどの外部画像生成サービスで作成し、PNGをWaddlyに取り込みます。Waddlyは画像を生成せず、参考画像を自動送信しません。参考画像を使う場合は外部サービスへ自分で添付してください。

明暗両方の背景で9コマすべてを確認し、本物の透過、安全な余白、隣のコマの破片、基準位置の安定を確かめます。クロップや位置の修正には「フレームを調整…」を使います。不均等なグリッド、欠けたポーズ、焼き込まれた背景、切れた絵は再生成や画像編集が必要な場合があり、位置合わせでは失われた画素を復元できません。取り込みと保守の手順は[README](../README.ja.md#画像の条件)を参照してください。
