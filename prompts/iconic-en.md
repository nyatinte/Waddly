# Iconic Style Prompt

A bold, simplified icon look built from a few shapes with uniform line width. Send this block after the shared Waddly sprite-sheet prompt.

```text
[Art style]
- Draw a bold, simplified silhouette built from a few large shapes.
- Use a single, consistent line width throughout.
- Fill shapes flat with a small number of colors; do not add gradients or texture.
- Choose readability at small size over fine detail.
- Make the silhouette recognizable at a glance.
```
