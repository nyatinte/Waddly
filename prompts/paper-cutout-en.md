# Paper Cutout Style Prompt

A paper-cutout look made of overlapping polygonal pieces with subtle paper texture. Send this block after the shared Waddly sprite-sheet prompt.

```text
[Art style]
- Build the character from overlapping, slightly irregular polygonal paper pieces.
- Give each piece a subtle paper-fiber texture.
- Show a thin inner edge or rim on each layer so the overlaps read as depth.
- Use flat, matte colors with slight tonal variation between pieces.
- Do not add a floor shadow, drop shadow, or glow.
```
