## Waddlyでできること

- 自分のペットの画像を登録できます。
- キー入力に合わせてペットが動きます。入力した文字やキーコードは保存しません。
- 待機中は呼吸やまばたきをし、時間がたつと眠ります。
- ペットはデスクトップ上でドラッグでき、好きな位置に配置できます。
- ペットはすべてのデスクトップ（Space）に表示されます。フルスクリーンアプリの上には表示されません。
- ペットを右クリックして「ペットをシェア」を選ぶと、動くペットの動画や画像をコピーしてSNSやチャットに貼り付けられます。

## はじめる

### Homebrewでインストール

```sh
brew tap nyatinte/waddly
brew install --cask nyatinte/waddly/waddly
```

更新するには `brew upgrade --cask waddly` を実行します。

### GitHub Releasesからインストール

[最新リリース](https://github.com/nyatinte/Waddly/releases/latest)から `Waddly-<バージョン>-macos-arm64.dmg` をダウンロードして開き、Waddlyをアプリケーションフォルダへドラッグします。同じリリースにある `.sha256` でチェックサムを確認できます。

配布アプリはad-hoc署名で公証されていないため、初回起動時にGatekeeperが止めることがあります。macOSが初回起動を止めた場合は、「システム設定」→「プライバシーとセキュリティ」を開き、セキュリティまでスクロールして「このまま開く」をクリックしてください。macOS 15以降ではControlキーを押しながらの「開く」では解除できません。

ソースから試す場合は、開発者向けの[ビルド手順](CONTRIBUTING.md)を参照してください。

### キー入力への反応を有効にする

「設定をはじめる」を選び、システム設定の「入力監視」でWaddlyをオンにします。一覧にない場合は、アイコンをドラッグするか＋ボタンで追加してください。確認が出たら「終了して再度開く」を選びます。

## 自分のペットを使う

### 画像を用意する

ペットの写真を用意して、Waddlyの「ChatGPTで開く」を選びます。ChatGPTに写真を添付して画像を作り、Waddlyに戻ってPNGを取り込んでください。他の画像生成サービスを使う場合は「プロンプトをコピー」を選びます。[プロンプト](prompts/ja.md)は下にも掲載しています。

<details>
<summary>生成用プロンプトを表示</summary>

```text
作りたいキャラクター：＜ここに書き換える＞

この行が空欄か「＜ここに書き換える＞」のままの場合は、どんなペットやキャラクターを作りたいか、先にユーザーへ質問してください。

上記のキャラクターで、Waddly用の3×3アニメーションスプライトシートを作成してください。参考にしたい画像を添付している場合は、その画像の個体を描いてください。

【キャラクター】
- 個体の特徴（種類、色、模様、体型）を全コマで保つ。

【画風】
- 16-bit機のゲーム風のピクセルアート。色数は少なく、輪郭は太く、陰影は2〜3段階。
- ぼかし、アンチエイリアス、グラデーション、光彩、写真風の表現は使わない。
- 9コマで同じ大きさ、同じ向き、同じカメラ位置にする。キャラクターの頭の上端・体の下端・左右の中心を、9コマですべて同じ位置にそろえ、動きで変えない。

【シートと配置】
- 透過PNGを1枚だけ出力する。3×3の9コマ。セルは同じ大きさの正方形にし、辺の長さは3で割り切れる値にする。
- 背景は本物の透明にし、キャラクターの輪郭の外側はアルファ0にする。チェッカー柄、白、灰色、色付きの背景、グラデーション、地面、影は描かない。
- キャラクター全体を各セルの中央50%の範囲（四辺に25%ずつの余白）に収める。耳、しっぽ、羽、キーボード、エフェクトもすべて内側に置く。
- セルの境界や隣のセルに1ピクセルでも触れたセルは、不正な出力とみなす。
- 収まらない場合は、キャラクターを小さくするのではなく、ポーズやエフェクトを控えめにする。
- 枠線、区切り線、番号、説明文、ロゴ、透かしは描かない。Enterキーの記号以外の文字は入れない。

【9コマ：左上から右へ、上から下】
1. リラックスして座っている
2. 1コマ目と同じ姿勢でまばたきしている
3. 集中した表情でキーボードに向かっている
4. ゆっくりタイピングしている
5. 4コマ目と少し違う姿勢でタイピングしている
6. 前のめりになって速くタイピングしている
7. 大きなEnterキーを勢いよく押し込む瞬間。参考画像を添付している場合はその勢いを参考にする
8. まぶたが重く、うとうとしている
9. 丸くなって安心して眠っている

【キーボードとエフェクト】
- 3〜7コマ目にだけ、9コマで同じ形・同じ大きさの小さなキーボードを描く。幅はセル幅の40%以下にする。
- 7コマ目はEnterキーを他のキーより大きく描く。Enterキーもセル幅の30%以内に収める。「↵」の記号は付けてもよいが、「Enter」などの文字は書かない。
- 7コマ目の星形のきらめきと衝撃線は、体のすぐそばに置く。線は短いものを2本までにし、体の外側へセル幅の5%を超えて伸ばさない。先端はセルの右端と下端から30%以上内側に置く。

この条件に合うスプライトシート画像だけを出力してください。
```

</details>

- 手持ちの画像をもとに作る場合は、ペットやキャラクターの画像をプロンプトと一緒に送ってください。
- 画像がない場合は、「丸い体の小さなペンギン」のように、作りたいキャラクターを文章で指定してください。画像の添付は不要です。

### 便利な機能とデータの保存先

- 反応しない場合は「動作しない場合」からWaddlyを再起動するか、システム設定で入力監視を確認してください。
- 新しいキャラクターを作るときは、「キャラクターを変更…」で表示言語に合った生成用プロンプトをChatGPTで開いたり、コピーしたりできます。ChatGPTを開くとプロンプトがページのURLに含まれるため、ブラウザの履歴にも残ります。「プロンプトをコピー」なら履歴に残りません。
- ペットのサイズ・動作・表示言語・表示先・ログイン時起動・入力監視は、ペットの右クリックメニューまたはメニューバーから変更できます。
- 取り込んだ画像や調整内容はMac内に保存され、元の画像ファイルはそのまま残ります。Waddlyが自分から外部へ画像やプロンプトを送信することはありません。

## プライバシー

キー入力はペットのアニメーションにだけ使い、保存・記録・送信はしません。画像やシェア用の動画・画像はMac上で処理し、自動ではアップロードしません。「Xでポストする」は「#ShareMyWaddly」入りの投稿画面を開くだけで、「ChatGPTで開く」のときだけ同梱のプロンプトがChatGPTに渡ります。

## メモリ実測

通常の利用では、メモリの物理フットプリント100 MB未満を目標にしています。計測手順と回帰テストは[CONTRIBUTING.md](CONTRIBUTING.md)を参照してください。

## アンインストール

Homebrewで入れた場合は、次を実行します。

```sh
brew uninstall --cask waddly
```

あわせて「システム設定 → プライバシーとセキュリティ → 入力監視」の一覧から Waddly を削除してください。

DMGで入れた場合は、Waddlyを終了してアプリケーションフォルダのWaddly.appをゴミ箱に入れてください。

## シェアとフィードバック

ペットの様子は X で [#ShareMyWaddly](https://x.com/hashtag/ShareMyWaddly) を付けてシェアしてください。不具合報告や機能要望は [GitHub Issues](https://github.com/nyatinte/Waddly/issues) へ。気に入ったらリポジトリに Star を付けてもらえると嬉しいです。
