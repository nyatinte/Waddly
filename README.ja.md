## Waddlyでできること

- 自分のペットの画像を登録できます。
- キー入力に合わせてペットが動きます。入力した文字やキーコードは保存しません。
- 待機中は呼吸やまばたきをし、時間がたつと眠ります。
- ペットはデスクトップ上でドラッグでき、好きな位置に配置できます。

## はじめる

WaddlyはApple Silicon搭載MacのmacOS 14以降に対応しています。サードパーティのHomebrew tapから配布します。

```sh
brew tap nyatinte/waddly
brew trust --cask nyatinte/waddly/waddly
brew install --cask waddly
```

更新するには `brew upgrade --cask waddly` を実行してください。ソースから試す場合は、開発者向けの[ビルド手順](CONTRIBUTING.md)を参照してください。

配布アプリはad-hoc署名で公証されていないため、初回起動時にGatekeeperが止めることがあります。「システム設定 → プライバシーとセキュリティ → このまま開く」で許可してください。macOS 15以降ではControlキーを押しながらの「開く」では解除できません。

初回起動時はセットアップガイドに沿って画像を登録してください。

### キー入力への反応を有効にする

2つ目のステップで「入力監視」の許可を求めます。アイコンを一覧へドラッグして、Waddlyをオンにしてください。

![Waddlyを入力監視の一覧へドラッグする様子](assets/examples/input-monitoring-guide.gif)

macOSが許可を反映するのはアプリの再起動後です。

## 自分のペットを使う

### 画像を用意する

[ChatGPT などの画像生成サービス](https://chatgpt.com/)に[生成用プロンプト](prompts/ja.md)を送ると、3×3 のスプライトシートを作成できます。

- 手持ちの画像をもとに作る場合は、ペットやキャラクターの画像をプロンプトと一緒に送ってください。
- 画像がない場合は、「丸い体の小さなペンギン」のように、作りたいキャラクターを文章で指定してください。画像の添付は不要です。

スプライトシートは手作業で作成することもできます。

| 参照画像                                                    | 3×3スプライトシート                                                         |
| ------------------------------------------------------- | ------------------------------------------------------------------- |
| ![参照用のnyatinte-bot画像](assets/examples/nyatinte-bot.png) | ![nyatinte-botの3×3透過スプライトシート](assets/examples/nyatinte-bot-3x3.png) |

### 画像の条件

- 透過PNGで、縦横が同じ長さの画像
- 縦横のピクセル数が3で割り切れること
- ファイルサイズは20 MB以下、各辺4096 px以下

長辺3072 pxを超えるシートは読み込み時に縮小され、個別画像は最大1024 pxになります。「アニメーション設定…」では動作ごとに複数の画像を追加できます。

画像はコマごとのPNGとして端末内に保存されます。元ファイルは変更せず、ネットワークへ送信しません。古いプロンプトで作成した画像はコマの順番が異なることがあるため、現在のプロンプトを使用してください。

## プライバシー

入力イベントはアニメーションの制御に使います。入力内容やキーコードを保存・記録・送信しません。画像は端末内に保存します。

## メモリ実測

通常の利用では、メモリの物理フットプリント100 MB未満を目標にしています。

| 使い方                                | メモリの目安                        |
| ---------------------------------- | ----------------------------- |
| 起動、キー入力、一般的な画像の取り込み                | 100 MB未満（目標）                  |
| 非常に大きなシート（例: 3072 × 3072・9コマ）の取り込み | 100 MBを超えることがあります（1.0での既知の例外） |

計測の手順と実測値は[メモリ計測のドキュメント](docs/MEMORY.md)を参照してください。
