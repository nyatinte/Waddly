## Waddlyでできること

- 自分のペットの画像を登録できます。
- キー入力に合わせてペットが動きます。入力した文字やキーコードは保存しません。
- 待機中は呼吸やまばたきをし、時間がたつと眠ります。
- ペットはデスクトップ上でドラッグでき、好きな位置に配置できます。
- ペットはすべてのデスクトップ（Space）に表示されます。フルスクリーンアプリの上には表示されません。
- ペットを右クリックして「ペットをシェア」を選ぶと、5秒のMP4（384 × 384）と3×3のPNGスプライトシート（9コマ）を端末内で作成します。動画または画像をコピーでき、「Xでポストする」では「#ShareMyWaddly」だけが入った投稿画面が開くので、文章とファイルは自分で添付します。シェア素材をファイルとして保存する機能はありません。

## はじめる

WaddlyはApple Silicon搭載MacのmacOS 14以降で動作します。インストール方法は2つです。

### Homebrewでインストール

今後の更新もHomebrewで行いたい場合に向いています。Homebrew 6.0以降ではサードパーティのCaskを明示的に信頼する必要があるため、次のコマンドで、インストールするCaskだけを信頼します。

```sh
brew tap nyatinte/waddly
brew trust --cask nyatinte/waddly/waddly
brew install --cask waddly
```

更新するには `brew upgrade --cask waddly` を実行します。信頼を取り消すには `brew untrust --cask nyatinte/waddly/waddly` を実行してください。

### GitHub Releasesからインストール

[最新リリース](https://github.com/nyatinte/Waddly/releases/latest)から `Waddly-<バージョン>-macos-arm64.dmg` をダウンロードして開き、Waddlyをアプリケーションフォルダへドラッグします。同じリリースにある `.sha256` でチェックサムを確認できます。

配布アプリはad-hoc署名で公証されていないため、初回起動時にGatekeeperが止めることがあります。「システム設定 → プライバシーとセキュリティ → このまま開く」で許可してください。macOS 15以降ではControlキーを押しながらの「開く」では解除できません。

ソースから試す場合は、開発者向けの[ビルド手順](CONTRIBUTING.md)を参照してください。

初回起動時はセットアップガイドに沿って画像を登録してください。

### キー入力への反応を有効にする

2つ目のステップで「入力監視」の許可を求めます。アイコンを一覧へドラッグして、Waddlyをオンにしてください。

許可しただけでは確認済みにはなりません。実際にキーを押してペットが反応すると「確認済み」になり、次のステップへ進めます。

![Waddlyを入力監視の一覧へドラッグする様子](assets/examples/input-monitoring-guide.gif)

macOSが許可を反映するのはアプリの再起動後です。「Waddlyを再起動」を押すと、再起動後も同じステップからセットアップが再開します。

## 自分のペットを使う

### 画像を用意する

「別のキャラクターを作る」で6種類の画風から1つを選び、キャラクターを説明します。初期設定はピクセルアートで、説明が空欄の場合は下の青いニット帽の丸いペンギンを使います。6つの作例は同じキャラクターと9つのポーズを使い、被写体ではなく画風を比較できます。プレビューから取り込み用の3×3 PNGを開け、画風名から対応するプロンプトブロックを確認できます。

| 画風とプロンプトブロック | 3×3シートの作例 |
| --- | --- |
| [ピクセルアート（初期設定）](prompts/pixel-art-ja.md) | [![ピクセルアートのペンギンシート](assets/character-styles/pixel-art.png)](assets/character-styles/pixel-art.png) |
| [手描き・線画](prompts/hand-drawn-ja.md) | [![手描きのペンギンシート](assets/character-styles/hand-drawn.png)](assets/character-styles/hand-drawn.png) |
| [アイコン・ミニマル](prompts/iconic-ja.md) | [![アイコンのペンギンシート](assets/character-styles/iconic.png)](assets/character-styles/iconic.png) |
| [レトロアニメ](prompts/retro-cartoon-ja.md) | [![レトロアニメのペンギンシート](assets/character-styles/retro-cartoon.png)](assets/character-styles/retro-cartoon.png) |
| [アニメ・セル塗り](prompts/anime-ja.md) | [![アニメのペンギンシート](assets/character-styles/anime.png)](assets/character-styles/anime.png) |
| [切り絵](prompts/paper-cutout-ja.md) | [![切り絵のペンギンシート](assets/character-styles/paper-cutout.png)](assets/character-styles/paper-cutout.png) |

1. セットアップまたはキャラクターの変更で、「別のキャラクターを作る」の「見た目のスタイルを選ぶ」を開きます。2列の一覧で比較し、説明を入力してください。カードにポインタやキーボードフォーカスを合わせると待機・まばたきを再生し、「選択したスタイルを再生」では反応を選んで確認できます。「視差効果を減らす」が有効なら静止画を表示します。画風を変えたり取り込みに戻ったりしても、説明と選択は保持され、保存済みのペットは変わりません。
2. 任意のサービスには「プロンプトをコピー」を使います。「プロンプトをコピーしてChatGPTを開く」なら[ChatGPT](https://chatgpt.com/)も開くので、そこで貼り付けます。Waddlyは画像生成や画像モデルの呼び出しを行わず、ローカルの参考画像を自動送信しません。
3. 必要なら外部サービスへ参考画像を手動で添付します。文章だけで指定する場合は添付不要です。
4. 透過PNGをダウンロードしてWaddlyに取り込み、9コマを確認し、必要なら「フレームを調整…」を使います。「続ける」か「適用」で保存するまで下書きであり、コピー操作では保存済みのペットや取り込み中の下書きは変わりません。

[日本語の共通プロンプト](prompts/ja.md)と[英語版](prompts/en.md)には、画風ブロックを1つ追加して手作業で組み合わせる手順もあります。初期設定のピクセルアート用プロンプト全文は次からコピーできます。

```text
作りたいキャラクター：青いニット帽をかぶった丸いペンギン。黒い背中、白いお腹、短いオレンジ色の足。

このキャラクターで、Waddly用の3×3スプライトシートを1枚作成してください。参考画像を手動で添付した場合は、その個体の特徴を保ってください。参考画像は任意です。

【キャラクターと静止ポーズ】
- 種類、顔、体の幅と高さ、配色、装飾品、向き、カメラ、大きさを9コマすべてで統一する。
- 頭の上端、体の下端、左右の中心を各セルの同じ座標に固定する。ポーズごとに拡大縮小や位置移動をしない。
- 小さなデスクトップペットで見やすい少数の静止ポーズにする。滑らかな全身運動ではなく、待機とまばたき、タイピングの差は小さくし、うとうとと睡眠では体の輪郭を保つ。大きな表情変化はEnterの反応に限り、体の基準位置は動かさない。

【シートと配置】
- 正方形の透過PNGを1枚出力する。同じ大きさの正方形セル9個を3×3に並べ、画像の辺の長さは3で割り切れる値にする。
- 本物のアルファ透過を使い、キャラクターと小道具の外側はアルファ0にする。偽のチェッカー柄、色付き背景、地面、投影する影は描かない。
- キャラクター全体、装飾品、キーボード、エフェクトは各セルの中央50%に収め、四辺に25%ずつ安全な余白を取る。セル境界への接触や隣のセルへのはみ出しは禁止。
- 収まらない場合はキャラクターを縮小せず、動作やエフェクトを控えめにする。コマ間の溝、区切り線、枠、番号、説明文、ロゴ、透かしは禁止。任意のEnterキー記号以外の文字は入れない。

【9コマ：左上から右へ、上から下】
1. 待機：リラックスして座っている。
2. まばたき：1コマ目と同じ姿勢で、まぶただけを閉じる。
3. キーボードに集中：注意を向け、手を構える。
4. タイピング：小さくゆっくりキーを押す。
5. タイピングの変化：4コマ目から手の位置だけを少し変える。
6. 高速タイピング：少し前傾し、手を速く動かす。体の基準位置は固定する。
7. Enterキーの反応：大きめのEnterキーを勢いよく押し、表情を強調する。基準位置は保つ。
8. うとうと：待機時の位置に座ったまま、まぶたが重くなる。
9. 睡眠：8コマ目と同じ座った輪郭で目を閉じ、休んでいる。

【キーボードとエフェクト】
- キーボードは3〜7コマ目だけに描く。登場するすべてのコマで位置、形、大きさ、遠近感、色を統一し、幅はセルの40%以下にする。
- 7コマ目だけEnterキーを強調し、セル幅の30%以内に収める。「↵」記号は任意だが、「Enter」の文字は書かない。
- Enterのきらめきと2本以下の短い衝撃線は体のそばの安全範囲に収め、隣のセルには描かない。

以上の条件と、続く画風の指定に合うスプライトシート画像だけを出力してください。

【画風：ピクセルアート】
- 16-bitゲーム風のピクセルアート。色数を絞り、太いピクセルの輪郭と2〜3段階の平坦な陰影を使う。
- ピクセルの輪郭をくっきり保ち、アンチエイリアス、ぼかし、グラデーション、光彩、写真風表現は使わない。全コマでピクセルの大きさを統一する。
```

### 画像の条件

- 透過PNGで、縦横が同じ長さの画像
- 縦横のピクセル数が3で割り切れること
- ファイルサイズは20 MB以下、各辺4096 px以下

AIが生成したシートは、プロンプトで位置を指定しても、コマごとにキャラクターの縦位置がずれる（ピッチのずれ）ことがあります。3×3シートを読み込んだあとに「フレームを調整…」を開くと、下書き上でクロップと位置合わせを編集できます。固定マッピング（待機2・入力中4・登場1・スリープ2）の9コマが表示され、1:1クロップを狭めてもキャラクターは動かず、位置合わせツールでキャラクター自体を移動できます。キャンバスはトラックパッドでパン／ズームでき、⌘+/⌘−/⌘0でも操作できます。中央十字線付きの調整前後プレビューで確認できます。

明暗両方のプレビュー背景で9コマすべてを確認し、白やチェッカー柄の焼き込み、絵の欠け、隣のコマの破片、不均等なグリッド、体の大きさの変化がないか確かめます。正方形のPNGとして読み込めても、ポーズや透過が正しいとは限りません。軽いずれはクロップや位置合わせで直せますが、失われた画素の復元、焼き込まれた背景の除去、欠けたポーズの追加はできません。その場合は再生成するか、画像編集アプリで透過と正しいコマ順を保って修正します。9コマを連続アニメーションとして扱わず、小さな表示で待機とまばたき、入力中、Enter、うとうとと睡眠の組ごとに比較してください。

長辺3072 pxを超えるシートは読み込み時に縮小され、個別画像は最大1024 pxになります。共通のキャラクター画面では、PNGファイルの選択、ウィンドウ全体へのドロップ、「クリップボードから貼り付け」（⌘V）が使えます。変更は「続ける」か「適用」を押すまで下書きのままです。

ペットを右クリックすると、サイズや動作、言語、表示先、ログイン時の起動を変更できます。項目が無効な場合は、必要な条件を標準メニューのヘルプで説明します。Dockまたはメニューバーのどちらかは表示したままにする必要があります。

Waddlyが前面にあるときは、画面上部のメニューバーにも標準のメニューが並びます。「Waddly」メニュー（「Waddlyについて」でバージョンとビルド番号を確認できます。ほかに「Waddlyを隠す」「Waddlyを終了」）、テキスト入力で⌘C／⌘Vが使える「編集」、開いているウインドウを扱う「ウインドウ」です。

設定完了後は「入力監視を設定…」から許可・状態確認・復旧の案内へ直接入り、「キャラクターを変更…」で画像を差し替えたり編集したりできます。初回・未完了時は「セットアップガイド…」が開きます。セットアップガイドと「キャラクターを変更…」は同じキャラクター画面を使い、選んだ画像は「続ける」か「適用」を押すまで下書きのままです。保存に失敗した場合は下書きを保持して再試行でき、下書きを変更したまま閉じると破棄の確認を表示します。保存済みのペットを表示している間は「現在使用中」、置き換える下書きがある間は「変更はまだ保存されていません」と表示されます。「適用」は保存済みのペットと異なる下書きがあるときだけ押せますが、セットアップガイドの「続ける」は変更がなくても次へ進めます。

登録後に別のキャラクターを作るときは、メニューバーかペットの右クリックメニューから「キャラクターを変更…」を開いてください。登録済みのペットや取り込み中の画像があっても、「別のキャラクターを作る」から利用できます。画風と説明を選び、アプリの表示言語で組み立てたプロンプトをコピーします。使いたい外部画像生成サービスに貼り付け、完成したPNGをこの画面で取り込んでください。コピー操作では現在のペットも下書きも変更されず、「適用」を押したときだけ保存します。Waddlyから画像生成サービスへ画像を送信することはありません。

画像がまだない場合は「まずサンプルで試す」で同梱のサンプルをすぐに表示できます。サンプルも他のペットと同じくローカルに保存され、「画像を変更」でいつでも差し替えられます。

画像はコマごとのPNGとして端末内に保存されます。フレーム編集を使った場合は、元の3×3シートとクロップ・位置合わせのメタデータもあわせて保存されます。元ファイルは変更せず、ネットワークへ送信しません。古いプロンプトで作成した画像はコマの順番が異なることがあるため、現在のプロンプトを使用してください。

## プライバシー

入力イベントはアニメーションの制御に使います。入力内容やキーコードを保存・記録・送信しません。画像は端末内に保存します。シェア素材もダイアログを開いたときに端末内で作成し、Waddlyからアップロードしません。コピーとXへの投稿はユーザーの操作で行います。Xロゴまたはテキストから投稿画面を開けますが、素材の添付や投稿は自分で行います。投稿画面にはハッシュタグ「#ShareMyWaddly」だけが入力され、本文は空のままなので自分で書けます。動画はファイルとしてコピーされるため、Xの投稿欄やチャットへ貼り付けて添付できます。

## メモリ実測

通常の利用では、メモリの物理フットプリント100 MB未満を目標にしています。非常に大きなシート（例: 3072 × 3072・9コマ）を取り込むと、この目標を超えることがあります（1.0での既知の例外）。計測手順と回帰テストは[CONTRIBUTING.md](CONTRIBUTING.md)を参照してください。フレーム調整エディタは、画像の入力条件が同じ間はBeforeとAfterのプレビューを各1件だけ再利用し、ズームやガイド表示の変更だけでは画像を再生成しません。後始末処理ではデコード済みシートとプレビューへの参照を破棄しますが、シートを閉じてもプロセス全体のメモリがすぐに元へ戻るとは限りません。

## コントリビュート

開発への参加方法は[CONTRIBUTING.md](CONTRIBUTING.md)を参照してください。

### プロンプトと作例の保守

`prompts/en.md` と `prompts/ja.md` を9コマの共通仕様と各言語の初期キャラクターの正本とします。フラットに配置した12個の `prompts/<style-id>-<lang>.md` は短い画風指定だけを持ちます。共通の `text` ブロックに説明を挿入し、画風の `text` ブロックを1つだけ追加します。READMEのピクセルアート全文は、既定の引数で呼び出す `SpriteSheetPrompt.load` と一致させます。`AppModelTests` が同期を検査し、`CharacterStylePromptTests` が6画風×2言語と説明の文字どおりの保持を検査します。

作例の保守チェックには `python3 Tools/generate_character_samples.py --check`、macOS上のテストとビルドには `mise run test` と `mise run build` を使います。作例を更新するときも、同じ青いニット帽のペンギンとコマ順を保ってください。自動検査はmacOS上の目視確認の代わりにはなりません。画像を出荷する前に、透過の縁、隣のコマの混入、基準位置の揺れ、静止ポーズの見やすさ、取り込みとプレビューの動作を確認してください。

作例の保守ツールには開発時だけ `Pillow==12.1.0` が必要です。Waddly本体はPillowに依存しません。
