# 効果音キューシート — Waddly プロモ

> このキューは [`tools/mix-30s.py`](tools/mix-30s.py) に実装済みです。
> `./tools/build-mix.sh 30` で再生成でき、マスターは **-14.0 LUFS / True Peak -1.3 dBFS** になります。
>
> **日本語版と英語版で同じマスターを使います。** 絵もタイミングも 1 フレームも違わず、
> 違うのは文字だけなので、音を分ける理由がありません。

`scripts/story.js` のビート表から書き出した実際のタイムコードです。
20 秒版は廃止し、**この 30 秒版に 20 秒版の「キャラクター交代」を組み込みました**（#17.5）。

> キャプションの文章は `scripts/locales/ja.js` / `en.js` にありますが、
> **音は言語に依存しません**（#3 のキャプションにも音は付けていません）。

**使うのは `audio/sfx-norm/` の方**（48 kHz / ステレオ / WAV）です。
`audio/sfx/` はダウンロードそのままの生ファイルで、次の問題があるため現場では使えません。

| 問題 | 例 | 対応 |
| --- | --- | --- |
| 音量がバラバラ | `key-single` はピーク **-18.9 dBFS**、他はほぼ -1 dBFS | すべて **-3 dBFS** にピーク正規化 |
| 頭に無音がある | `key-single` は **154 ms**、`pop-drop` は **830 ms** の無音から始まる | 無音を削除してトランジェントを先頭に |
| 終わりがぶつ切り | — | 最後 30 ms をフェードアウト |

正規化の内訳は `audio/tools/prepare-sfx.sh` の実行ログ、または `audio/sfx-norm/` を再生成して確認できます。

下のレベルは **正規化済みファイル（ピーク -3 dBFS）に掛けるフェーダー値**です。
BGM を -19 LUFS で敷いたときの目安なので、実際は耳で詰めてください。

## 打鍵の割り当て（#5 / #24）

打鍵の時刻は `scripts/story.js` の `keyTimes` に入っています。

**1 打 = 2 層**にしています。ラップトップのキーは「thock（胴鳴り）＋クリック」なので、
`key-hard.wav`（-3 dB）と `key-single.wav`（-5 dB）を重ねます。
薄いクリック 1 枚だけだとマウスの音に聞こえていました。

- 区間: **3.20–7.25 秒**（キーボード）と **26.20–27.55 秒**（Return へ向かう打鍵）
- ピッチは **±2.5 %**、音量は **±1.2 dB** を固定シードで揺らす
- 間隔が **60 ms 未満**の打鍵は間引く
- さらに下に **`key-typing-bed.wav`（実録の打鍵シーケンス）を -23 dB** で敷き、1 台のキーボードとして聴かせる
- 読み込むファイルは先頭の無音を **-48 dB しきい値で除去**（発音が映像より遅れないように）

打鍵の時刻を取り出すには:

```sh
cd promo/audio
node tools/extract-keys.cjs scripts/story.js
```

## 9 コマの飛翔（#15）

`14.10 + i × 0.135`（i = 0〜8）が各コマの出発時刻です。9 コマは**ドロップ領域の中で 3×3 に並びます**。

```
14.100  14.235  14.370  14.505  14.640  14.775  14.910  15.045  15.180
```

`whoosh-fast.wav`（0.57 秒）を各時刻で鳴らし、**2 つ目以降は -1.5 dB ずつ下げる**と最後が自然に消えます。
9 回すべて同じ音量だと騒がしくなります。**4 回に 1 回に間引いても十分**です。

## Return の重ね方（#26）

27.55 の 1 点に 3 層を重ねます。ここだけは手をかけてください。

| 層 | ファイル | レベル | 役割 |
| --- | --- | --- | --- |
| 打鍵 | `key-hard.wav` | -12 dB | 「カチッ」という指の感触。0.31 秒 |
| 衝撃 | `impact-big.wav` | -8 dB | 画面の閃光とカメラシェイク。8.97 秒あるので**頭 1.2 秒だけ**使う |
| 低音 | `hit-sub.wav` | -14 dB | 胸に来る土台。1.10 秒 |

**タイミングを 1〜2 ミリ秒ずらす**と厚みが出ます（打鍵を 0 ms、衝撃を +6 ms、低音を +2 ms）。
`impact-big.wav` は頭に無音がある場合はトリムして、**波形の立ち上がりを 27.55 に合わせて**ください。

代わりの衝撃音として `impact-alt.wav`（5.99 秒）と `impact-sub.wav`（3.00 秒）も入れてあります。
