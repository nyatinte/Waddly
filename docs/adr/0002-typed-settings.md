# ADR 0002: 型付きのアプリ設定

- 状態: 採用
- 更新日: 2026-10-01

## 背景

設定値を `UserDefaults` の文字列キーと生の整数・数値・真偽値で各所から読み書きしていた。キー名や初期値が呼び出し側に分散し、enum 値の変換も個別に行われていた。

## 決定

- `Defaults` パッケージは追加せず、`AppSettings` で既存の `UserDefaults` を型付きで包む。
- 設定キー、初期値、enum の変換を一か所にまとめる。画像マニフェストとウィンドウ位置の保存キーも同じ層に集約する。
- 既存のキー名と保存形式を維持する。既存値の移行は不要で、`TypingMotion` と `AppLanguage` の未知の値は従来の初期値へ戻す。
- Dock とメニューバーの両方を非表示にする既存の起動時ガードを維持する。

## 結果

外部依存を増やさずに、設定の読み書きと既定値を型付きのプロパティから扱える。将来キーや保存形式を変える場合は `AppSettings` に明示的な移行処理を追加する。
