# 用語集

| 用語 | このプロジェクトでの意味 |
| --- | --- |
| Typibara | 入力に反応するmacOSの作業用ペットアプリ。本POCの参考例。 |
| 常駐アプリ | Dockまたはメニューバーから操作し、登録したペット画像をデスクトップ上に表示するアプリ。 |
| オーバーレイパネル | 登録したペット画像を他のウィンドウの上に表示する透明なパネル。常時ドラッグ可能なため、ペットの範囲では背後のクリックを遮る。 |
| 入力イベント | キーが押されたことを示すmacOSのイベント。Waddlyは入力時刻とEnterキーかどうかだけを使い、キーコードは処理中だけ判定に使う。 |
| listen-only | 入力イベントを観測するだけの方式。イベントの変更、破棄、合成はしない。 |
| 入力監視権限 | macOSが、他のアプリを使用中のキーボード入力イベントをアプリに許可するためのプライバシー権限。 |
| スプライト | アニメーションの1コマとして表示する画像。3×3透過PNGからコマを切り出し、カテゴリごとに保存する。 |
| 通常待機 | 直近のキー入力後、短時間だけ入力がない状態。 |
| 睡眠状態 | 20〜30秒入力がないときの状態。呼吸のような小さな動きを行い、5分後は静止する。 |
| Swift toolchain | Swiftコンパイラーと標準ライブラリなど、Swiftアプリをビルドするための環境。 |
| Releaseビルド | 最適化を有効にして配布・実利用に近い設定でビルドしたアプリ。メモリ目標はこの状態で測る。 |
