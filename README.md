# Waddly

自分のペットを macOS のデスクトップに住まわせる、軽量なデスクトップコンパニオンです。標準のペンギンを、自分のペットのスプライトに置き換えて使えます。

[English README](README.en.md)

## できること

- キー入力に合わせてペットが動きます。アプリはキーの内容やキーコードを保存せず、入力イベントの発生だけを使います。
- 待機中は小さく呼吸し、ときどきまばたきします。しばらくすると睡眠し、5 分後にアニメーションを止めます。入力監視は復帰用に続きます。
- ペットはデスクトップ上でドラッグでき、位置を記憶します。表示サイズは 180px、240px、320px から選べます。
- ペットを右クリックするか、メニューバーアイコンをクリックするとメニューが開きます。サイズ変更、位置リセット、表示切替、一時停止、ログイン時起動、終了を選べます。
- アプリアイコンは同梱ペットの通常フレームから生成します。`assets/01-idle.png` を差し替えて再ビルドするとアイコンも更新されます。
- AppKit、Core Graphics、Core Animation を使った Swift アプリです。外部ライブラリは使っていません。

## 動作環境

- macOS 13 以降
- Swift 6 を含む Xcode Command Line Tools
- 現在のビルドスクリプトは、実行した Mac の CPU アーキテクチャ向けにビルドします

## ビルドと起動

```sh
./macos/build.sh
open build/Waddly.app
```

初回起動時は「システム設定 → プライバシーとセキュリティ → 入力監視」で Waddly を許可してください。許可されない場合もアプリとメニューバーは起動し、メニューから設定を開けます。

配布用ディスクイメージを作るには次を実行します。

```sh
./macos/package.sh
```

`dist/` に `Waddly-0.1.0-macos-<architecture>.dmg` ができます。Developer ID 証明書がこの Mac にないため、標準ビルドは ad-hoc 署名で、公証は行いません。インターネット配布で Gatekeeper の警告を避けるには Developer ID 署名と Apple の公証が必要です。署名 ID は `WADDLY_SIGN_IDENTITY` 環境変数で指定できます。

## 自分のペットに置き換える

リポジトリには、4×4 のスプライトシートをプレビューし、16 枚の PNG に分けるツール `index.html` が含まれています。

1. ローカルサーバーを起動します。

   ```sh
   python3 -m http.server 8000
   ```

2. ブラウザーで `http://localhost:8000` を開き、画像を選択します。
3. 分割結果を確認し、「assets フォルダーに PNG を保存」を選びます。フォルダー選択に対応しないブラウザーでは PNG が個別にダウンロードされます。
4. 既存の `assets/01-*.png` から `assets/16-*.png` をバックアップし、新しい PNG に置き換えます。ファイル名はそのまま使ってください。
5. `./macos/build.sh` を実行し、作り直した `build/Waddly.app` を起動します。

### ChatGPT 画像生成プロンプト

ペットの写真や既存イラストを参照画像として添付し、次のプロンプトを使ってください。分割ツールは白背景とマゼンタ色の区切り線を見つけます。

```text
添付した画像を唯一のキャラクター参照として、同じペットのスプライトシートを1枚作ってください。

正方形の画像を、4列×4行の均等な16マスに分けます。各マスにはペットを全身で1体だけ描き、キャラクターの大きさ・向き・線・色・配置を全コマで揃えてください。マス同士でキャラクターを重ねないでください。

マスの順番は左上から右へ、次の行へ進みます。
1. 正面の通常待機
2. 目を閉じたまばたき
3. 左を見て驚く
4. 右を見て驚く
5. ノートPCを見る
6. 普通にタイピング
7. 素早くタイピング
8. 画面から顔をのぞかせる
9. 嬉しそうにタイピング
10. 集中して作業
11. ジャンプ
12. 片手で作業
13. うとうとする
14. 座ったまま眠る
15. 両手を上げて喜ぶ
16. やさしく持ち上げられる

背景は完全な白にし、マスの境界と画像の外周には、鮮やかなマゼンタ (#ff00ff) の太い直線を入れてください。縦横それぞれ5本の連続した区切り線にします。ペットにはマゼンタを使わないでください。影、文字、吹き出し、小物、装飾枠は追加しないでください。出力は正方形のPNG画像1枚にしてください。
```

画像生成結果によっては区切り線や背景を正しく分割できない場合があります。その場合はスプライトシートを修正してから取り込んでください。

## プライバシー

Waddly は読み取り専用の `CGEventTap` でキー入力イベントを監視します。アプリ内で使うのは入力イベントのタイミングだけです。入力文字列やキーコードの保存、ログ出力、ネットワーク送信は行いません。入力監視を許可しなくてもアプリは起動できます。

## メモリ実測

Apple Silicon 搭載 Mac、macOS 27.0、Release ビルドで測定しました。Waddly の起動約 13 秒後、待機アニメーション中の `ps` RSS は 52,176 KB（約 51 MiB）、`footprint` の物理メモリフットプリントは約 12 MB（ピーク約 13 MB）でした。プロセスや OS の状態で数値は変動します。タイピング中と、5 分以上静止させた状態は未計測です。

RSS には共有ライブラリなども含まれます。macOS のフットプリントはアプリが物理メモリに与える影響を見るための別指標です。どちらも、このプロジェクトの目標である 100 MB を下回る測定結果でした。
